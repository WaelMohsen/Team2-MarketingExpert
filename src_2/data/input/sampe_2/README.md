# Sample 2 Input

This folder uses the requested name `sampe_2`. It contains:

- `meta_data.json`: Campaign, adset, ad, creative, and daily Meta insight data.
- `conversations.json`: WhatsApp conversations and observed business outcomes.
- `products.json`: Product reference data used by order line items.

The files are copied from the workspace `samples (2)` directory so the v2 POC is
self-contained. They should be treated as immutable raw inputs.
